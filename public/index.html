Bắt đầu

Ba bước là xem được

  1. Tải và cài

    Chọn nền tảng ở trên. Android cài từ Google Play, máy tính tải bộ cài.

  2. Thêm danh sách của bạn

    Dán link M3U hoặc chọn file. TS IPTV không kèm sẵn kênh nào.

  3. Xem, hoặc phát lên TV

    Chạm biểu tượng TV trong trình phát để chuyển kênh lên Android TV.

Kiểm tra file tải về

Bản desktop kèm file SHA256SUMS.txt. So mã băm của file bạn tải với mã trong file đó.

Get-FileHash .\TS-IPTV-*-Setup.exe -Algorithm SHA256
shasum -a 256 TS-IPTV-*-macOS-arm64.dmg
